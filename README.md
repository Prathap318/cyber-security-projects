# Cybersecurity Projects

A portfolio of beginner-friendly defensive cybersecurity projects built with Python.

## Projects

### 1. SOC Log Analyzer
Analyzes authentication logs to identify repeated failed login attempts and highlight potentially suspicious source IP addresses.

**Skills:** Python, log analysis, SOC monitoring, incident triage

### 2. File Integrity Monitor
Creates SHA-256 hashes for files and compares later scans to detect added, modified, or deleted files.

**Skills:** Python, hashing, file integrity monitoring, security controls

### 3. Phishing URL Checker
Performs a safe, offline heuristic check of a URL for common phishing indicators such as IP-based hosts, suspicious URL structure, and risky keywords. It does not visit or execute the URL.

**Skills:** Python, URL analysis, phishing awareness, defensive security

## How to Run

Each project is self-contained and uses Python 3. No external packages are required.

```bash
python soc-log-analyzer/analyzer.py
python file-integrity-monitor/monitor.py
python phishing-url-checker/checker.py
```

> These projects are intended for learning, defensive security practice, and portfolio demonstration. Use only on systems and data you are authorized to analyze.
